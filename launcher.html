Что умеет

Сборки

Каталог Modrinth и CurseForge, установка .mrpack, импорт из Modrinth App, свои сборки с Fabric / Quilt / Forge / NeoForge, управление модами, шейдерами и ресурспаками.

Скины и плащи

Вход аккаунтом mc-ru.org — скин и плащ из кабинета подтягиваются в игру, включая HD и анимацию.

Microsoft-аккаунт

Лицензионный вход по коду устройства: любые серверы, официальные скины.

Серверы сообщества

Список серверов mc-ru.org внизу главного меню — выбрал и играешь, адреса вводить не надо.

Discord

Rich Presence показывает друзьям, в какую сборку ты играешь.

Java сама

Нужную Java скачивает лаунчер, память и аргументы JVM — в настройках.

Требования

  • Windows 10 / 11, 64-бит. Один файл Eta.exe, установка не нужна.
  • macOS 11 Big Sur и новее, Intel. На Apple Silicon — через Rosetta (система предложит сама).
  • 4 ГБ ОЗУ минимум, для модов — 8 ГБ. Java скачивается автоматически.

Установка

Windows

  1. Скачай Eta.exe и запусти.
  2. SmartScreen может предупредить (сборка не подписана): нажми Подробнее → Выполнить в любом случае.
  3. Данные лаунчера лежат в %APPDATA%\Eta.

macOS

  1. Открой .dmg, перетащи Eta в Программы.
  2. При первом запуске: ПКМ по Eta → Открыть → Открыть (Gatekeeper).

Не нашёл кнопку скачивания или что-то не запускается — пиши в Discord, канал #помощь.
