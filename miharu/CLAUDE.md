# Miharu — заметки для работы над плагином

- Каждый апдейт, который отдаётся пользователю, поднимает версию на +1 (patch): `pom.xml` → `<version>`,
  имя jar `Miharu-<версия>.jar`, упоминание в README. 0.2.0 → 0.2.1 → 0.2.2 …
- Сборка: Java 25, Maven (`mvn package`), NMS — `scripts/install-paper-server.sh`.
- Ключи yml с точкой («1.8», «duel-1.8») Bukkit раскладывает во вложенные секции — при обходе `getKeys(false)`
  такие ключи ломаются; для перечисляемых секций использовать ключи без точек.
- Тесты — локальный Paper 1.21.11 + mineflayer; на сервер пользователя ничего не заливать, jar отдавать в чат.
